## 本轮实现

定位为安静的中文自我探索工具。完成提问、选择牌阵、选牌、揭牌、基础解读、保存与回顾。图鉴作为学习入口，日记承接抽牌后的个人理解。不复制竞品牌面与文案。

## 后续优先级

1. 为当前符号化牌面补充统一风格、许可清楚的完整插画，提升象征学习体验。
2. 增加服务端 AI 解读，建立请求限流、超时与保留原牌的重试机制；继续保留无网络基础解读。
3. 增加 JSON 备份导入，再评估账号与跨设备同步。
4. 用实际使用反馈检验流程完成率、解读可理解性与日记回访，再决定是否增加牌阵。
